## Caret 0.3.5

- Section reads now return the text that fits the remaining per-turn allowance. The evidence assistant can use that passage and report any gaps.
- Overleaf Git errors now distinguish server outages, authentication or permission problems, connectivity issues, and branch conflicts.

All 31 evidence-assistant and Overleaf regression tests passed. The signed app was verified from the read-only disk image, including startup with isolated data and compilation of a sample LaTeX document.

This Apple Silicon build uses the separately installed Caret runtime and LaTeX tools.
